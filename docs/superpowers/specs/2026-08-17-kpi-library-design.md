# 系统设置指标库与 KPI Dashboard 联动设计

## 背景

在系统设置中新增“指标库”子菜单，参考给定的指标库截图，让用户可以搜索、按分类筛选并选择指标。点击保存后，将已选指标应用到“决策分析”的 KPI Dashboard。

## 目标

- 在现有 `settings.html` 的左侧设置菜单中增加“指标库”。
- 复用现有系统设置的同页子视图与 `?sub=` 深链接模式。
- 提供指标搜索、分类筛选、多选、清空和重置能力。
- 使用与现有项目一致的浏览器本地存储持久化指标配置。
- 保存后让 `decision.html` 的 KPI Dashboard 动态展示已启用指标。
- 保持现有顶部 KPI 总结带和计划员待办入口不变。

## 不在本次范围

- 指标公式编辑器、计算引擎或实时数据接入。
- 后端接口、账号级/角色级权限矩阵。
- 指标拖拽排序、复杂布局编排。
- 改造排程、库存和计划员待办数据源。

## 页面结构与交互

### 系统设置入口

- 左侧现有 `resource-menu` 增加按钮：`data-settings-sub="kpi-library"`，标题为“指标库”。
- 新增 `settings-sub-kpi-library` 子视图。
- `switchSettingsSub()` 通过现有 `?sub=kpi-library` URL 状态激活该视图。
- 进入该页面时读取已保存配置；首次没有配置时使用默认选中项。

### 指标库内容区

页面采用看板式指标库布局，移除截图中的顶部“总览 / 指标库 / 数据查看 / 插单模拟”标签栏，因为这些不是系统设置指标库页面的一部分。

内容从上到下包括：

1. 页面标题与说明。
2. 搜索框：按指标名称或描述过滤。
3. 分类筛选：全部、产能类、设备类、人员类、柔性类、效率类、排序质量类、计划类、瓶颈类、库存类、订单类。
4. 指标区域标题：显示当前分类下的匹配数量、全库总数与全局已选数量。
5. 4 列响应式指标卡片网格。每张卡片展示勾选状态、名称、描述和单位。
6. 底部操作栏：重置选择、保存并应用到决策分析。

“清空选择”放在页面标题右侧、已选数量旁边；它只清除当前编辑态，不直接保存。指标区域标题中的数量口径固定为：`匹配数量 / 全库总数`，例如筛选产能类时显示 `8 / 40`；已选数量始终为全局已选项数量，不受当前搜索和分类影响。

默认选择以下 5 个指标（名称与稳定 ID 一一对应）：

- `production-total`：产能统计
- `line-utilization`：产线利用率
- `theoretical-capacity`：理论产能
- `actual-capacity`：实际产能
- `production-utilization`：产能利用率

交互规则：

- 搜索与分类筛选可以叠加。
- 切换分类或搜索不会改变已选择的指标。
- “清空选择”立即清除当前编辑态选择，但不写入持久化配置。
- “重置选择”将当前编辑态恢复为最近一次已保存配置；首次使用时恢复为默认 5 项。
- 未保存的勾选只存在于当前页面状态。
- 保存成功后写入配置、更新已保存快照并提示“已应用到决策分析 KPI 看板”。
- 无匹配项时显示“未找到匹配指标”。
- 允许保存空选择；决策分析展示空状态而不是恢复旧卡片。

## 数据模型与持久化

使用 localStorage 键：

```text
aps.kpi.library.config.v1
```

值结构：

```json
{
  "selectedIds": ["production-total", "line-utilization"],
  "updatedAt": "2026-08-17T00:00:00.000Z"
}
```

指标元数据至少包含：

- `id`
- `category`
- `name`
- `description`
- `unit`
- `value`
- `trend`
- `note`

读取异常、JSON 解析失败或结构不合法时，回退到默认 5 项，不阻塞页面。保存时统一使用 JSON 序列化。

## 决策分析联动

`decision.html` 加载 KPI Dashboard 时读取相同的 localStorage 配置：

- 有配置时，仅渲染 `selectedIds` 对应的指标卡片。
- 没有配置时，使用默认 5 项。
- `selectedIds` 为空时，指标卡片区域显示空状态提示，说明可前往系统设置 → 指标库选择指标。
- KPI Dashboard 保留现有顶部总结带与计划员待办入口；只替换指标卡片区域。
- 指标卡片沿用现有 dashboard 的视觉语言、响应式栅格、主题变量和键盘可访问性。
- 指标定义中的演示值用于当前原型展示，不改变原有排程业务状态。

## 错误处理与反馈

- 搜索无结果：显示空状态。
- localStorage 不可用或内容损坏：使用默认配置并继续渲染。
- 保存成功：toast 提示，并更新已保存快照。
- 保存异常：toast 提示“指标配置保存失败，请重试”，保留当前编辑态，避免静默丢失选择。

## 验证计划

手工验证：

1. 从系统设置打开“指标库”，确认菜单高亮与 `?sub=kpi-library` 深链接。
2. 确认默认 5 项选中、分类数量、搜索结果与已选计数。
3. 勾选、取消、清空、重置，确认未保存状态不会影响决策分析。
4. 保存后打开决策分析，确认 KPI Dashboard 卡片只展示已选指标。
5. 清空并保存，确认 Dashboard 显示空状态。
6. 刷新设置页与决策分析页，确认配置仍保持。
7. 切换深色/浅色主题并检查布局。
8. 回归检查现有系统设置、决策分析顶部总结带和计划员待办入口。

自动化/静态检查：

- 对涉及的 HTML 内嵌脚本执行语法检查。
- 运行现有 `tests/operations-pages.test.js`。
- 检查修改后的 HTML 包含指标库菜单、持久化键、保存入口和 Dashboard 渲染入口。

## 方案选择

采用“现有设置页新增子视图 + 共享 localStorage + 决策分析动态渲染”的方案。它与项目当前的设置菜单、URL 子视图和本地状态持久化模式一致，改动集中，且能保持用户已确认的页面边界。
