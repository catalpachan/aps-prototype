# 插单模拟 APS 风格重构设计

**日期：** 2026-08-18  
**状态：** 已确认，待实施

## 背景与目标

`insert-simulation.html` 已具备插单选择和模拟计算交互，但目前采用浅色独立页面，未遵循 APS 原有的深色界面语言。此次工作仅重构视觉结构与样式，使它与 `schedule-history.html`（历史记录）保持一致，同时保留现有功能、演示数据和页面入口。

## 确认的方案

采用“历史记录深色骨架，无侧边栏”的方案：

- 保留 APS 全局顶部导航（Logo、决策分析、排产操作、系统设置），对齐历史记录页。
- 不引入历史记录页的左侧导航栏。
- 页面主体延续历史记录页的深色背景、工具栏、面板、表格、状态与描边规范。
- 两张表继续纵向排列；在窄屏上保留横向滚动能力。

未采用的方案：仅替换颜色（结构层级不足）；完整复制历史记录页（包含侧栏，违背已确认约束）。

## 页面结构

```
APS 全局顶部导航
└── 深色主内容区（无侧栏）
    ├── 顶部工具栏
    │   ├── 左：插单模拟标题与简短说明
    │   └── 右：已选 N 项 + 运行模拟主按钮
    ├── 插单列表面板
    │   ├── 标题和订单数量
    │   └── 可选择订单表格
    └── 模拟结果面板
        ├── 标题与运行状态提示
        └── 模拟结果表格
```

## 组件与视觉规范

### 全局导航与主内容区

- 使用项目已有的 APS 顶部导航标记与视觉规则，避免重新定义另一套导航样式。
- 主内容区使用历史记录同系深色底色；最大宽度、内边距和响应式断点与同类排产页面保持协调。
- 返回可视化交互工作台的操作作为低优先级文本/次级操作呈现，不与“运行模拟”竞争。

### 顶部工具栏

- 左侧显示“插单模拟”，可保留简短辅助说明以明确 What-if 模拟的用途。
- 右侧显示动态“已选 N 项”提示和唯一的蓝色高优先级主按钮“运行模拟”。
- 选择数量只反映已勾选订单，随复选框操作实时更新。
- 未选任何订单时，运行操作沿用现有提示，不清空已有模拟结果。

### 插单列表与模拟结果面板

- 两者使用历史记录式深色卡片面板、细边框及层次明确的面板标题栏。
- 表头采用比面板稍亮的深色；行文本、分隔线、悬停和选中状态沿用 APS 信息密度与对比关系。
- 复选框采用项目统一的蓝色强调色；全选框需要继续呈现已选、未选及半选状态。
- 状态列使用既有的成功/关注色语义；数字、百分比与容量字段保持易扫描的对齐方式。
- 长物料描述继续截断并通过原有 `title` 提供完整内容，不使表格撑破布局。

## 数据与行为边界

- 保留 `insert-simulation.js` 的订单示例数据、模拟结果计算、全选/半选状态、空选择提示和可访问性属性。
- 不增加后端接口、数据持久化、本地缓存或新的业务规则。
- 继续由工作台中的“插单模拟”入口进入本页；返回操作继续回到可视化交互工作台。
- 视觉状态与语义状态一致：选择计数、按钮可用状态、提示文本和结果表均基于当前的 JavaScript 状态。

## 实施边界与文件责任

| 文件 | 责任 |
| --- | --- |
| `insert-simulation.html` | 调整为 APS 顶部导航 + 无侧栏深色内容骨架；将运行操作置于顶部工具栏。 |
| `insert-simulation.css` | 以历史记录页为视觉基准，重建本页的深色工具栏、面板、表格、状态与响应式规则。 |
| `insert-simulation.js` | 尽量不改变业务计算；仅在必要时调整状态提示挂载点或类名。 |
| `tests/operations-pages.test.js` | 保留交互覆盖，并补充结构/样式契约检查。 |

## 验收与测试

1. 运行现有插单模拟交互测试：选择、全选/半选、空选择提示、模拟结果计算与可访问性状态均保持通过。
2. 添加/更新页面结构测试：存在 APS 全局导航、深色顶部工具栏、右侧运行按钮、插单列表和模拟结果面板。
3. 本地浏览器检查桌面与窄屏：导航、工具栏、表格和面板保持 APS 风格；窄屏表格可横向滚动且不发生页面溢出。
4. 执行 JavaScript 语法检查及相关 Node 测试套件。

## 非目标

- 不修改模拟算法、订单字段、结果字段或示例数据。
- 不增加导出、筛选、后端保存、真实排产执行或权限控制。
- 不将历史记录页的左侧边栏复制到插单模拟页。
