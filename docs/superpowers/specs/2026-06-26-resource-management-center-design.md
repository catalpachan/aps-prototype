# 资源管理中心设计

## 目标

在排产操作页“全要素资源匹配预检”区域新增“资源管理中心”入口，并将它放在“执行资源匹配”按钮左侧。点击后进入独立资源主数据工作台，用于查看各分厂设备与人力资源主数据。

## 页面入口

入口添加在 `aps-optimization.js` 动态注入的 `#aps-resource-check-card` 标题栏内：

- 新增 `#aps-resource-center-btn`，文案为“资源管理中心”。
- `#aps-resource-center-btn` 位于 `#aps-resource-match-btn` 左侧。
- 保留原有 `#aps-resource-match-btn` 执行资源匹配行为。
- 点击资源管理中心跳转到 `resource-center.html`。

## 页面架构

`resource-center.html` 必须参考 `order-center.html` 的管理中心样式：

- APS 顶栏与主导航保持一致。
- 页面主体使用 `resource-center-shell`，结构与订单管理中心一致：左侧侧栏 + 右侧工作区。
- 左侧宽度使用 `196px`，深色侧栏背景、品牌区、按钮风格与订单管理中心保持一致。
- 右侧工作区使用同色系表格卡片，不使用旧版截图化大蓝表格风格。

## 左侧三级菜单

一级菜单：

- 总装
- 两器
- 注塑
- 钣金
- 控制器

每个一级菜单下有二级菜单：

- 设备管理
- 人力资源

设备管理下有三级菜单：

- 品目表
- 资源表
- 制造BOM表
- 配套分厂提前期
- 生产订单表

人力资源下有三级菜单：

- 出勤模式表
- 日历表

默认选中“总装 / 设备管理 / 品目表”。

## 右侧表单内容

右侧主卡片包含：

- 标题随当前三级菜单变化。
- 说明文字显示当前路径。
- 搜索框，placeholder 为“输入关键词查询”。
- 当前路径标签，例如“总装 / 设备管理 / 品目表”。
- 横向可滚动的数据表。
- 表头包含：序号、资源编码、资源名称、所属分厂、资源类型、状态、产能/班、负责人。
- 模拟资源、设备、人力、日历等主数据行。
- 底部分页栏：总数、上一页、当前页、下一页、跳转输入与跳转按钮。

## 测试

自动化测试验证：

- 排产操作增强脚本包含资源管理中心按钮，并且位于资源匹配按钮之前。
- 点击监听跳转到 `resource-center.html`。
- `resource-center.html` 存在。
- 页面包含订单管理中心同风格布局关键 CSS。
- 页面包含五个一级分厂菜单。
- 页面包含设备管理/人力资源二级菜单和所有三级菜单。
- 页面包含搜索框、主数据表、分页栏。
- 表头包含资源管理中心表单字段。
