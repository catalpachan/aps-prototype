# 可视化交互工作台模式页签设计

## 目标

将排产操作页“可视化交互工作台”的周视角拆分为两个互斥展示的模式：

- 甘特图模式：用于查看全周负荷、日期概览和产线甘特排程。
- 列表模式：用于按日期查看排产任务明细。

默认进入甘特图模式。月、周、日视角及现有分厂筛选、执行方案、任务编辑逻辑保持不变。

## 页面结构

在周视角 `#view-panel-week` 内容顶部新增模式页签：

- `甘特图模式`
- `列表模式`

页签位于工作台标题栏下方、周视角内容上方，作为内容区的二级导航。它不与“月 / 周 / 日”视角切换、分厂筛选或“执行方案”按钮混排。

周视角内容拆分为两个模式面板：

### 甘特图模式

包含以下现有模块：

- `.workbench-note-row`
- `#week-calendar`
- `.week-gantt-wrap`

说明条、颜色图例、七天负荷卡片和周甘特图保持现有行为。点击日期卡片继续切换到对应日期的日视角。

### 列表模式

包含：

- 紧凑的七天日期切换条。
- `#week-day-tables` 生成的 `.week-day-table-card`。

紧凑日期切换条复用周视图日期和负荷数据，但不触发日视角跳转。点击日期只更新列表模式当前日期，并重新渲染对应日期的任务列表。

## 状态与交互

新增周视图模式状态，合法值为：

- `gantt`
- `list`

初始值固定为 `gantt`。

模式切换遵循以下规则：

- 切换模式不改变当前月、周、日视角。
- 两种模式共享 `selectedWeekDayIndex`。
- 甘特图模式选择日期后切换到日视角的现有行为不变。
- 列表模式选择日期时仅刷新列表，不进入日视角。
- 两种模式共享分厂筛选结果。
- 每个日期已有的列表分页状态继续保存在 `weekDayPageByIndex` 中。
- 重新进入周视角时保留当前周视图模式，首次进入仍为甘特图模式。

页签采用按钮实现，并提供：

- `role="tablist"`
- `role="tab"`
- `aria-selected`
- 可见的激活状态
- 键盘焦点样式

## 渲染边界

`renderWeekView()` 继续负责生成共享的周日期、任务和甘特数据缓存。

渲染流程调整为：

1. 生成周日期、任务行和缓存数据。
2. 渲染甘特模式的日期卡片与甘特图。
3. 渲染列表模式的紧凑日期切换条。
4. 根据 `selectedWeekDayIndex` 渲染 `.week-day-table-card`。
5. 根据当前模式控制两个模式面板的显隐。

模式切换本身不重复构造任务数据，仅切换面板并在需要时刷新列表，避免不必要的重排。

## 视觉规范

- 沿用当前深色 APS 工作台样式。
- 模式页签使用紧凑分段控制样式，激活项使用现有蓝色主色。
- 页签区域不增加外层卡片，避免卡片嵌套。
- 列表模式日期条高度低于甘特模式的日期卡片，以便为表格保留更多垂直空间。
- 窄屏下页签保持横向排列；日期切换条允许横向滚动，不隐藏日期。
- 模式切换只使用轻微透明度过渡，不引发布局尺寸跳动。

## 兼容性

- 月视角和日视角 DOM、渲染与交互保持不变。
- `setWorkbenchView()` 仍负责一级视角切换。
- 分厂筛选继续调用 `renderActiveWorkbenchView()`。
- 周甘特任务双击编辑、日期进入日视角、列表排产顺序编辑和分页保持现有能力。
- Cloudflare 无扩展名 `/collab` 路由继续支持页面增强。

## 测试

自动化测试应验证：

- 周视角存在“甘特图模式”和“列表模式”两个页签。
- 甘特图模式为默认激活项。
- 甘特模式面板包含 `workbench-note-row`、`week-calendar` 和 `week-gantt-wrap`。
- 列表模式面板包含紧凑日期切换条和 `week-day-tables`。
- 模式切换函数只接受 `gantt`、`list`。
- 列表日期点击不会调用进入日视角的逻辑。
- 两种模式共享 `selectedWeekDayIndex`。
- 月、周、日一级视角切换仍然存在。

浏览器验证应覆盖：

- 默认周视角显示甘特图模式。
- 切换列表模式后甘特内容隐藏、列表内容显示。
- 紧凑日期条能切换列表日期。
- 切回甘特图模式后选中日期保持一致。
- 分厂筛选在两个模式下均生效。
- 桌面与窄屏下无内容重叠或文本溢出。
